PROJECT OVERVIEW

UserHub

UserHub is an Angular-based user management project that allows users to explore profiles, view their posts, and see comments related to each post through a simple and responsive interface.

01 — ABOUT THE PROJECT

A Simple Way to Explore User Data

UserHub was created to practice Angular by building a real-world style application where different types of related data can be explored through the user interface.

The project starts with users and their profiles. When a user is selected, their related posts are displayed, and each post can be opened to view its comments.

02 — PURPOSE

Why I Built UserHub

The main purpose of this project was to strengthen my understanding of Angular by working with dynamic data, reusable components and interaction between different parts of an application.

  • Practice Angular component-based development
  • Work with dynamic user data
  • Display related posts and comments
  • Practice data flow between components
  • Build a responsive dashboard interface
