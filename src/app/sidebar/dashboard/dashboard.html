ABOUT PROJECT

About This Project

This project is a dynamic User Dashboard application that fetches data from JSON and displays it in a structured and interactive way. It allows users to view user information, their posts, and comments related to each individual post.

Why I Built This Project

I built this project to practice working with JSON data, API integration, data fetching, and dynamic data rendering. The main purpose was to understand how data can be fetched from an external source and displayed dynamically on a frontend application.

How It Works

The dashboard first displays a list of users. When a user is selected, their details are displayed. From there, the user can view posts belonging only to that selected user. Each post also has its own comments, which are fetched and displayed separately.

Project Flow

01

Users

Users are fetched from JSON and displayed on the dashboard.

02

User Details

Click on a user to view their detailed information.

03

User Posts

View posts created by the selected user only.

04

Post Comments

View comments belonging to each individual post.
